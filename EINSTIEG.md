# Einstieg für neue Mitarbeitende

Wir arbeiten **in der Cloud**, über Claude Code im Browser (https://claude.ai/code).
Auf dem eigenen Rechner muss nichts installiert werden.

## Was du brauchst

- ein Claude-Konto mit Pro oder Max
- ein GitHub-Konto (kostenlos)

## Einrichtung (einmalig, etwa 10 Minuten)

1. **GitHub-Konto anlegen** auf https://github.com/signup.
2. **Jakob deinen GitHub-Namen schicken.** Er lädt dich zum Projekt ein.
3. **Einladung annehmen**, über den Link in der E-Mail von GitHub oder direkt auf
   https://github.com/codegodjakob/schatzsuche/invitations.
4. **GitHub mit Claude verbinden** auf https://claude.ai/connect-github.
5. **Loslegen:** Auf https://claude.ai/code eine neue Sitzung starten, als Projekt
   `codegodjakob/schatzsuche` auswählen und schreiben, was du tun willst.

Claude liest die gemeinsamen Spielregeln (`CLAUDE.md`) dann von selbst. Du musst sie ihm nicht erklären.

## Jeden Tag

Neue Sitzung auf https://claude.ai/code → Projekt `schatzsuche` wählen → Aufgabe sagen,
zum Beispiel: „Nimm das nächste offene Issue, das mir zugewiesen ist, und erledige es.“
Claude holt den neuesten Stand, arbeitet in einem eigenen Zweig und reicht die Änderung als Vorschlag ein.
